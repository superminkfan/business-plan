## Форматы

- **PNG/JPG** — просмотр и печать; **SVG** — векторное увеличение.
- **HTML** — локальный просмотр в браузере. GitHub показывает код: скачать репозиторий и открыть файл. v6 работает без внешних библиотек; старые экспорты VIP содержат внешние библиотеки для дополнительных подсказок, PNG/SVG доступны независимо от них.
- **`.source.html`** — сохранённый редактируемый фрагмент исходника. Это не обязательно самостоятельная HTML-страница; для просмотра использовать соседний `.html`.
- **`.context.json`** — геометрия, даты, решения и контрольные суммы. Относительные ссылки v6 обновлены после переноса.
- **`generate_v6.py` / `render_v6.cjs`** — генератор и растеризация полного плана.

Файлы `.source.html`, PNG, SVG, JPG и сохранённые HTML перенесены без изменения содержимого. Неизменённые архивные контексты относятся к своему историческому состоянию. При изменении геометрии обновлять исходник, производные форматы, контрольные суммы и основные документы вместе.
